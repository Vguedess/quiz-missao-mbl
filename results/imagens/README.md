# Imagens das faixas de resultado

Envie os **seis arquivos JPG** diretamente nesta pasta, com estes nomes exatos:

- `renan-romantico.jpg` — 25% até menos de 50%
- `cute-japa-livro-amarelo.jpg` — 50% até menos de 76%
- `amanda-vettorazo-oculos.jpg` — 76% até menos de 90%
- `onca-estilizada.jpg` — 90% até 100%
- `renan-microfone.jpg` — acima de 100% até 110%
- `patch-onca-brasil.jpg` — acima de 110%

Os arquivos serão associados às faixas do quiz e ao cartão de compartilhamento depois do upload.

**Como enviar:** GitHub → `results/imagens/` → **Add file** → **Upload files** → selecione as imagens → **Commit changes**.

Esta subpasta fica na estrutura do projeto estático. Os caminhos web finais serão `/results/imagens/<arquivo>.jpg`.
